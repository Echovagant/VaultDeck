# 局域网访问

## 1 监听与暴露面

| 组件       | 监听地址              | 是否对局域网开放 |
| ---------- | --------------------- | ---------------- |
| 后端 API   | `127.0.0.1:3000`      | ❌ 仅本机        |
| Nginx      | `0.0.0.0:8443`（TLS） | ✅ 唯一入口      |
| PostgreSQL | `127.0.0.1:5432`      | ❌ 仅本机        |

后端**不要**改成 `0.0.0.0`：那会把无 TLS 的 API 端口直接暴露到局域网。局域网只需访问 Nginx 的 8443。

## 2 防火墙（需要管理员）

以管理员身份运行 PowerShell：

```powershell
New-NetFirewallRule -DisplayName "VaultDeck HTTPS" -Direction Inbound -Protocol TCP -LocalPort 8443 -Action Allow
```

确认规则：

```powershell
Get-NetFirewallRule -DisplayName "VaultDeck HTTPS" | Select-Object DisplayName,Enabled,Direction,Action
```

不需要放行 3000/5432。若不希望所有网络配置文件都开放，可加 `-Profile Private`，但前提是当前网络被识别为“专用网络”。

## 3 客户端访问

- 地址：`https://<server-ip>:8443`
- 首次访问需信任自签 CA（`certs/ca.crt`），否则浏览器会提示不安全。

导入方式：

| 平台    | 步骤                                                                                       |
| ------- | ------------------------------------------------------------------------------------------ |
| Windows | 双击 `ca.crt` → 安装证书 → 当前用户 → 受信任的根证书颁发机构                               |
| Android | 设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书                                              |
| iOS     | 发送 `ca.crt` 到设备 → 安装描述文件 → 设置 → 通用 → 关于本机 → 证书信任设置 → 启用完全信任 |

Firefox 使用独立证书库，需要在“证书颁发机构”中单独导入。

临时验证（不导入证书）：浏览器提示时选择“继续访问”，仅用于测试，不要长期这样使用。

## 4 验证步骤

1. 手机与服务器连接**同一个** WiFi 或有线网络。
2. 打开 `https://<server-ip>:8443`。
3. 用 `leader` 登录，能看到项目列表。
4. 上传一个文件，确认进度与校验通过。

## 5 排障

| 现象                  | 可能原因                           | 处理                               |
| --------------------- | ---------------------------------- | ---------------------------------- |
| 手机完全打不开        | 防火墙未放行 8443                  | 执行第 2 节命令                    |
| 手机打不开，本机可开  | 路由器开启 AP 隔离（客户端隔离）   | 在路由器关闭“AP 隔离/客户端隔离”   |
| 能打开但 API 请求失败 | 代理配置缺失或后端未启动           | 检查 Nginx 日志与 `127.0.0.1:3000` |
| 证书警告反复出现      | 未导入 CA 或导入到错误存储         | 重新导入到“受信任的根证书颁发机构” |
| 部分设备访问超时      | 设备在不同网段（如 5G 热点与内网） | 确认设备与服务器同一网段           |

## 6 安全边界

- 只暴露 8443，且强制 TLS。
- 不要为验证方便临时关闭防火墙或放行 3000。
- 局域网内任何人只要拿到地址就能看到登录页；账号与权限仍是唯一的访问控制，密码强度与账号停用要及时。
