# docs/ops

运维文档目录。M0-01 建立占位，随平台验证与部署实现逐步填充。

## 规划内容

| 文档                                                   | 来源任务         |
| ------------------------------------------------------ | ---------------- |
| 平台验证报告（Nginx 并发、长路径与文件锁、WinSW 拉起） | T-M0-10～T-M0-12 |
| 证书签发与客户端导入说明                               | T-M0-15          |
| 安装、升级、回滚手册                                   | T-M0-16、M4      |
| 备份与恢复演练记录                                     | T-M4-04～T-M4-06 |
| 主机策略清单（电源、更新、Defender、防火墙）           | T-M4-09          |

## 脱敏

运维文档会进入公开仓库，因此不得写入设备型号、采购信息、内网网段、主机名、盘符路径与真实姓名。具体值放 `_private/`，此处只写步骤与占位符。
