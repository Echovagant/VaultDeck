# deploy/windows

Windows 单机部署件目录。M0-01 建立约定，M0-13～M0-16 填入实现。

## 发布包结构

    releases/<version>/     每次发布一个不可变目录
    current.txt             指向当前版本目录名，回滚即改此文件
    shared/                 跨版本共享：配置文件、证书
    runtime/node/           内置 Node 运行时
    logs/                   运行日志

不使用符号链接：Windows 下普通用户创建符号链接受限，改用指针文件。

## 职责边界

| 组件     | 职责                                                |
| -------- | --------------------------------------------------- |
| WinSW    | 守护后端与 Nginx，崩溃重启、免登录运行、日志重定向  |
| Nginx    | TLS 终止、静态资源、/api 反代、限流；不下发文件正文 |
| 后端     | 文件流式下发、Range、业务与权限                     |
| 安装脚本 | 服务注册、迁移、证书部署、启动与冒烟                |
| 回滚脚本 | 切换 `current.txt` 指针并重启                       |

## 约束

- 全部离线：依赖、运行时、安装件随包提供，安装过程不访问公网。
- 服务注册、证书导入计算机存储、防火墙规则需要管理员权限。
- 路径不得写死盘符，使用 `${APP_ROOT}`、`${DATA_ROOT}` 占位。
